# 重複程式碼偵測

處理大量複製貼上的 C# 遺留程式碼:找出重複區塊、列出每個 `if` 與測試項目、畫出 `if` 節點圖,並提供右側作業區整理成函式。

- **不用安裝**:用瀏覽器開 `index.html` 即可。全部在本機執行,不上傳、不連網。
- 需要的檔案要放在同一個資料夾:`index.html`、`core.js`、`ifs.js`、`graph.js`、`sample.js`。

## 快速開始

1. 用瀏覽器(Chrome / Edge)開啟 `index.html`。
2. 按「載入範例」試玩,或貼上你的程式碼,或按「載入檔案…」選 `.txt` / `.cs`。
3. 按「找重複」、「列出 if 與測試項目」、「畫 if 節點圖」。
4. 看到要處理的區塊,按「→ 作業區」送到右側整理。

頁面左邊是原程式碼與分析結果,右邊是作業區。螢幕窄時會上下排列。

## 功能

### 1. 找重複
找出出現 2 次以上的相似區塊,即使有些行不同也算(例如 `else` 裡多一行)。

每一組顯示:幾處、約幾行、相似度。以第一處為基準,點其他處會並排顯示差異:

| 顏色 | 意思 |
|---|---|
| 無色 | 兩邊完全相同 |
| 黃 | 結構相同,只有變數名或常數不同 |
| 紅 | 只在基準有 |
| 綠 | 只在這一處有 |

**參數**

| 參數 | 預設 | 說明 |
|---|---|---|
| 最少重複行數 | 30 | 只算實際程式行,不含空行、註解、單獨的大括號 |
| 容許差異行數 | 3 | 區塊中間可以插入或不同幾行,仍算同一組 |
| 最低相似度 % | 60 | 相同的行占整段的比例 |
| 忽略變數名與常數值 | 勾選 | 勾選時,改過變數名、數字、字串的複本仍算重複 |

### 2. 列出 if 與測試項目
列出每個 `if`:行號、條件、巢狀深度、有無 `else` / `else if`、相同條件出現幾處。可篩選條件文字、只看有相同條件的、讓相同條件排在一起。

點一列展開測試項目:

- **前置條件**:要先讓哪些外層 `if` 為真或為假,才走得到這裡。
- **測試組合**:把條件拆成子條件,用 MC/DC 產生最少的組合,每個子條件都獨立影響過一次結果。例如 `a && (b || c)` 只要 4 組。
- **邊界值**:`x > 0` 取 0 和 1;`== null` 測 null 與非 null;`IsNullOrEmpty` 測 null、空字串、有內容。
- **注意**:恆真條件、多餘或被蓋住的子條件會提醒。

「下載全部測試項目 (.txt)」可輸出整份清單,改動前當檢查表。

### 3. 畫 if 節點圖
- 一個節點是一個 `if`。巢狀的往右一欄,連線標「真 / 假」;`else if` 接在前一個下面,標「假」。
- 相同條件的節點同色,右側標次數。
- 點一個節點:圈出同條件的其他處,顯示資訊。下方列出同條件的其他處,點一個就並排比對兩個 `if` 底下的程式碼。
- 超過 200 個 `if` 不畫。請用圖上方的「行範圍」填起訖行縮小,或按「只看這個 if 及其內部」。

### 4. 作業區
- 左邊每個重複區塊、`if`、測試項目都有「→ 作業區」按鈕,會連同 `// === 來源` 標題一起附加進去。
- 可直接編輯、貼上。另有「複製全部」、「下載 .cs」、「清空」。
- 內容暫存在這個瀏覽器,關掉再開還在。要長期保存請下載。

## 建議流程
1. 一次貼一個類別或一個方法(分段貼,不用整個專案)。
2. 先用「找重複」看有哪些大塊重複,把要處理的送到作業區。
3. 用「列出 if 與測試項目」把要改動的區塊的測試項目也送到作業區。
4. 在作業區把重複抽成函式(出現 2 次以上才抽、不要巢狀函式、超過 30 行也要拆),再補上測試。
5. 改完用「找重複」重新檢查。

## 限制
- 分析的是**文字與結構相似度**,不是真正的編譯與型別分析。判斷與改寫由你負責。
- 「相同條件」比的是文字:`a > 0` 與 `0 < a` 不會視為相同。
- 子條件超過 8 個時,不自動產生組合。
- 沒有大括號的 `if`,範圍用簡化規則判斷,極特殊的寫法可能判錯。
- 測試項目是**依條件算出的輸入組合**,不含預期結果,要靠你補。
- 載入檔案以 UTF-8 讀取。若是 Big5 編碼的 `.cs`,中文會變亂碼,請先轉成 UTF-8,或直接貼上。
- 效能:小範例已驗證。一次貼上萬行以上的速度尚未實測。

## 開發
```bash
node test.js         # 重複偵測
node test-ifs.js     # if 清單與測試項目
node test-graph.js   # 節點圖版面
```
- 核心邏輯(`core.js`、`ifs.js`、`graph.js`)不依賴瀏覽器,瀏覽器與 node 都能載入。
- 直接在 `main` 上做小步提交,訊息依 Conventional Commits(`feat`、`fix`、`docs`…)。
- 設計脈絡見 [DOUBLE-DIAMOND.md](DOUBLE-DIAMOND.md)。
